# Exercise 3 - mut and immut

Write a program that:

- Declares an immutable variable `greeting` with the value `'Hello'`.
- Declares a mutable variable `count` with the value `0`.
- Increments `count` by `1`.
- Prints `greeting` and `count`.

Expected output:

```
Hello
1
```

Then, try to reassign `greeting`. Observe the compiler error.
